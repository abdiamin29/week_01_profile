# Week 01: Semantic HTML Profile Page

A personal profile webpage built with semantic HTML5 and deployed via GitHub Pages.

- **Live URL:** https://abdiamin29.github.io/week_01_profile/

## Reflection

Building this profile page taught me how to structure a webpage using semantic HTML5 elements, validate my markup with the W3C validator, and track changes using Git. Deploying the repository to GitHub Pages showed me how local code becomes a live, accessible website on the internet.
